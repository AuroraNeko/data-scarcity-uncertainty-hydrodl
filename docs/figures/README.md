# README figures

`experiments/figures/make_readme_figures.py --copy-to-docs` regenerates the
three PNGs here from the current protocol and `results/tables/`.
`figure_provenance.json` records input hashes, aggregation and group rules.
The error bars show sample SD across three model seeds.

The same script produces the primary LPU-Stream schematic through
`src/visualization/architecture.py`. Its PDF and editable SVG are under
`results/figures/`; a 300-dpi preview is under `results/figures/readme/`.
The provenance file also records hashes of the schematic and model source.

The manuscript protocol diagram is generated by
`src/visualization/protocol_figure.py`, called from
`experiments/figures/make_figure_set.py`. Calibration and test have
separate rows so that the forcing-context hatch does not obscure target days.
The three experiment cards distinguish the primary sample, disjoint endpoint
replications, and overlapping full-basin benchmark.

Scientific plots use vector PDF/SVG output. Raw QR, global CQR and predicted-regime
CQR use different markers and line styles as well as colors. Figure captions
distinguish training-seed SD from basin-bootstrap confidence intervals.
